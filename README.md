# API Data Diri

API sederhana yang menampilkan data diri (Portfolio API).

## Cara Menjalankan

1.  Clone repository ini
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Jalankan server:
    ```bash
    npm start
    ```
4.  Buka browser atau Postman ke `http://localhost:3000`

## Endpoints

- `GET /`: Menampilkan data diri lengkap
